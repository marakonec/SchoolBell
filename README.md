# Шкільний дзвінок та повітряна тривога

**Українська** | [English](README.en.md)

Програма для Windows 10/11, що за розкладом відтворює дзвінки на урок і з уроку, хвилину мовчання та сигнали повітряної тривоги й відбою для обраної громади або району.

## Зміни в цьому форку (версія 1.3.0)

Форк зроблено для закладу, де вже є своя система дзвінків і потрібна лише трансляція тривоги та відбою через колонки.

- **Стандартні звуки в комплекті.** Інсталятор кладе в `C:\Program Files\SchoolBell\sounds\` готові файли `air-alert.mp3` (сирена й голосове повідомлення «Увага! Повітряна тривога! Негайно пройдіть до найближчого укриття», двічі) та `all-clear.mp3` (дзвін і «Увага! Відбій повітряної тривоги», двічі). Якщо на вкладці «Звуки» свій файл не обрано або він зник, програма сама підставляє стандартний, тож тривога ніколи не звучить як резервний «біп». Голос за замовчуванням Anatol, інші голоси (Marianna, Natalia, Volodymyr) лежать у `sounds\voices\` і обираються на вкладці «Звуки». Звуки згенеровано скриптом `scripts/make_sounds.py` (сирена й дзвін синтезовані, голос RHVoice).
- **Профіль «лише тривога» при першому запуску.** Дзвінки на уроки й хвилина мовчання вимкнені, періоду «Вихідні» немає, тож тривога лунає в будь-який день, коли ПК увімкнений. Розклад і хвилину мовчання за потреби вмикаються в інтерфейсі як і раніше.
- **Тривога, що вже триває під час запуску, оголошується.** Раніше, якщо ПК вмикали посеред тривоги, сигнал не звучав. Тепер він звучить, якщо цього дня цю тривогу ще не оголошували. Перезапуск програми посеред уже оголошеної тривоги сирену не дублює.

## Можливості

- **Розклад уроків**: один для всіх обраних днів тижня. Дзвінок на урок лунає на початку, з уроку — в кінці.
- **Звуки**: mp3 (а також wav, wma, m4a) обираються в інтерфейсі. Файл копіюється в папку програми, тож оригінал можна видалити.
  - Опція «Різні звуки для дзвінка на урок і з уроку». Коли вона увімкнена, на головній вкладці дві кнопки дзвінка.
- **Хвилина мовчання**: свій файл, час і дні. Має пріоритет: якщо збігається з дзвінком, дзвінок звучить одразу після неї.
- **Повітряна тривога**: відстеження для громади або району через API «Повітряна тривога» (UkraineAlarm). Автоматичні сигнали тривоги й відбою вмикаються окремим прапорцем. Тривога, оголошена на всю область чи район, теж враховується. Якщо API повідомляє рівень загрози, картка тривоги стає червоною або жовтою і показує причину. Під час тривоги дзвінки лунають як звичайно. Сповіщення Windows не надсилаються: лише звук.
- **Періоди неактивності**: дні та проміжок часу, коли нічого не лунає автоматично (дзвінки, хвилина мовчання, тривога).
- **Головний вимикач** (канікули/свята): вимикає все автоматичне, включно з тривогою. Стан зберігається після перезавантаження.
- **Ручні кнопки**: дзвінок (або два), хвилина мовчання, тривога, відбій, зупинка. Працюють завжди.
- **Стрічка «Сьогодні»** на головній вкладці займає ліву частину вікна до самого низу; праворуч — картка тривоги і кнопки ручного запуску. Угорі рядок стану: «Зараз звучить» з кнопкою «Стоп» або «Наступне» з таймером. Нижче таймлайн дня: усі дзвінки й хвилина мовчання за розкладом (відтворено / пропущено й чому / попереду), ручні запуски, тривоги, відбої, зміна рівня тривоги та вмикання/вимикання розкладу. Червона позначка показує поточний час. Записи зберігаються в `C:\ProgramData\SchoolBell\journal\` (по файлу на день, 14 днів), тож переживають перезапуск програми.
- **Прослуховування** кожного звуку на вкладці «Звуки».

## Стабільність

| Ситуація | Що відбувається |
|---|---|
| Перезавантаження ПК | Планувальник запускає програму при вході (потрібен автовхід у Windows). |
| Програму закрили або вона впала | Планувальник перевіряє кожні 5 хв і запускає знову. При критичній помилці програма перезапускає себе сама. |
| Закрили вікно | Вікно ховається в трей, програма працює. |
| ПК запустився через хвилину після дзвінка | Дзвінок пролунає (запас 90 с). Старіші дзвінки не лунають «запізнено». |
| Перевели годинник назад | Той самий дзвінок двічі не пролунає. |
| mp3 не відтворюється | Спроба через MCI; якщо й так не вдалось — резервний сигнал і банер у вікні. |
| Файл налаштувань пошкодився | Відновлення з резервної копії `settings.json.bak` і попередження у вікні. |
| Немає інтернету | Дзвінки працюють; у вікні банер «немає зв'язку з сервісом тривог». |
| Сон Windows | Програма забороняє сон, поки працює. |

## Встановлення на шкільний ПК

1. Запустіть `SchoolBell-Setup-1.2.1.exe` і пройдіть кроки майстра. Права адміністратора потрібні.
   Інсталятор:
   - копіює програму в `C:\Program Files\SchoolBell`;
   - налаштовує автозапуск: завдання Планувальника «SchoolBell» запускає програму при вході, перевіряє кожні 5 хв і перезапускає її, якщо вона закрита;
   - за вашим вибором вимикає сон ПК і забороняє перезавантаження для оновлень Windows з 7:00 до 19:00;
   - створює ярлики в меню «Пуск» і (за бажанням) на робочому столі;
   - реєструє програму в «Програми та компоненти»;
   - одразу запускає програму.
2. Увімкніть **автовхід у Windows** через [Sysinternals Autologon](https://learn.microsoft.com/sysinternals/downloads/autologon) (посилання є на останній сторінці інсталятора). Бажано окремий користувач без прав адміністратора. Після входу екран можна заблокувати (Win+L), звук лунатиме далі.
3. У BIOS увімкніть **Restore on AC Power Loss → Power On**, щоб ПК сам вмикався після відключення світла.
4. Відкрийте програму і налаштуйте:
   - вкладка «Розклад»: уроки, дні, хвилина мовчання;
   - «Звуки»: оберіть файли та прослухайте;
   - «Тривога»: натисніть «Оновити список регіонів», оберіть область → район → громаду, «Перевірити зараз»;
   - «Неактивність»: за потреби;
   - натисніть **«Зберегти зміни»**.

**Оновлення:** запустіть новий `SchoolBell-Setup-*.exe` поверх старого. Налаштування і звуки збережуться.
**Видалення:** «Параметри → Програми → Шкільний дзвінок → Видалити». Інсталятор запитає, чи видаляти налаштування і звуки.
**Тихе встановлення** (наприклад, на кілька ПК): `SchoolBell-Setup-1.2.1.exe /S`. Встановлюються всі компоненти.

## Збірка інсталятора

Версія задається в `src/SchoolBell.App/SchoolBell.App.csproj` (`<Version>`).

**macOS або Linux:**
```bash
brew install --cask dotnet-sdk   # .NET 10 SDK (Linux: https://dotnet.microsoft.com/download)
brew install makensis            # NSIS (Linux: sudo apt install nsis)
./scripts/build-installer.sh
```

**Windows:**
```powershell
winget install Microsoft.DotNet.SDK.10
winget install NSIS.NSIS
powershell -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1
```

**GitHub Actions** (нічого не встановлюючи локально): завантажте проєкт у репозиторій GitHub, відкрийте Actions → «Build installer» → Run workflow. Готовий інсталятор з'явиться в Artifacts. Якщо надіслати тег `v1.0.1`, інсталятор додасться до Release.

Результат: `dist/SchoolBell-Setup-<версія>.exe` (близько 60–70 МБ). На шкільному ПК нічого додатково встановлювати не треба: .NET вбудовано в програму.

Скрипти спершу проганяють тести логіки (`tests/SchoolBell.Core.Tests`) і зупиняються, якщо вони не пройшли.

## API тривог

- Без ключа програма використовує публічне дзеркало `siren.pp.ua`. Воно віддає дані офіційного API «Повітряна тривога» з лімітом 50 запитів на хвилину з однієї IP. Програма робить 4 запити на хвилину (інтервал 15 с).
- Для надійності отримайте власний ключ на <https://api.ukrainealarm.com> і вставте його на вкладці «Тривога». Тоді запити йдуть напряму до `api.ukrainealarm.com`.
- Після запуску програми перше отримане значення не вважається «початком тривоги». Так сирена не пролунає повторно, якщо ПК перезавантажився посеред тривоги.
- Програма — додатковий канал оповіщення і не замінює сирену та офіційні процедури.

## Де що лежить

```
C:\Program Files\SchoolBell\SchoolBell.exe     програма
C:\ProgramData\SchoolBell\settings.json        налаштування (+ settings.json.bak)
C:\ProgramData\SchoolBell\sounds\              копії звукових файлів
C:\ProgramData\SchoolBell\regions.json         кеш списку регіонів
C:\ProgramData\SchoolBell\journal\             стрічка подій по днях (зберігається 14 днів)

```

## Якщо щось не так

- **Немає звуку:** перевірте гучність Windows і пристрій виведення за замовчуванням. Натисніть «Прослухати» на вкладці «Звуки».
- **Windows 10/11 «N»:** встановіть *Media Feature Pack* (Параметри → Програми → Додаткові компоненти), інакше mp3 може не відтворюватися.
- **Програма не стартує після перезавантаження:** перевірте автовхід і завдання «SchoolBell» у Планувальнику завдань. Журнал встановлення: `C:\ProgramData\SchoolBell\logs\install.log`.
- **Подробиці помилок:** `C:\ProgramData\SchoolBell\logs\error.log`.
